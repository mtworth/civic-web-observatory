About

The web that powers civic society, government agencies, public records, nonprofit services, deserves to be studied on its own terms. It's easy to lose track of as the wider web goes through a large technology transformation: AI-driven traffic, shifting search behavior, hosting platforms consolidating. Civic Web Observatory tracks this layer of the web directly, not through sentiment or opinion, but through what these sites actually serve.

It performs lightweight, transparent, homepage-only checks of public-interest websites: U.S. federal, state, and local government agencies, plus registered nonprofits. It records availability, machine-readability, hosting/DNS hints, and basic accessibility signals. It does not bypass bot protections, crawl private areas, or perform vulnerability scanning.

Sources

The domain list is built from two public datasets:

  • .gov domains, from the live CISA .gov domain registry, covering federal, state, and local government entities.
  • Nonprofit domains, extracted from IRS Form 990 e-file filings, which include an organization's reported website alongside its EIN, name, and filing details.

Both are merged into one seed list of roughly 318,000 domains.

Methods

Each domain gets one homepage-only visit per crawl: no following links, no crawling beyond the homepage. A single crawl covers a deterministic 1/90th slice of the seed list, so every domain is revisited on a rolling 90-day cycle.

What's checked, per domain:

  • DNS resolution and hosting/ASN hints
  • HTTP and HTTPS availability, redirect behavior, TLS certificate validity
  • robots.txt, sitemap.xml, and llms.txt presence
  • Basic HTML signals (title, meta description, language, mobile viewport) and static accessibility checks
  • Detected technologies (CMS, analytics, frameworks) from page markup and headers

Raw observations are kept as-is, not converted into a single derived score. A status code and a certificate expiry date are recorded as themselves, not folded into a composite number.

What this doesn't do

No bypassing bot protection, no proxy rotation, no CAPTCHA solving, no fingerprint spoofing. A domain that blocks the crawler is recorded as blocked, not worked around. If a site returns a WAF/CDN challenge page, that's the observation.
