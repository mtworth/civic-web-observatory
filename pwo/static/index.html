Methodology

Public Web Observatory performs lightweight, transparent, homepage-only checks of public-interest websites. It records availability, machine-readability, hosting/DNS hints, and automated accessibility signals. It does not bypass bot protections, crawl private areas, or perform vulnerability scanning.

What gets crawled

For each domain, the crawler requests only: the homepage over HTTPS and HTTP, /robots.txt, /sitemap.xml, and /llms.txt. No deeper links are followed.

Crawler identity

Every request identifies itself with a transparent User-Agent:

PublicWebObservatoryBot/0.1 (+https://publicwebobservatory.org/bot; contact: hello@publicwebobservatory.org)

What it does not do

  • No proxy rotation or fake browser fingerprinting
  • No CAPTCHA solving or bot-challenge evasion
  • No login attempts or admin path probing
  • No aggressive retries — blocks are recorded, not bypassed

Scoring

Raw observations only. This dataset deliberately avoids collapsing signals into a single opaque score — every field shown (HTTPS validity, TLS issuer, missing alt text, etc.) is a direct, individually verifiable fact about the domain at the time it was checked.

Current data source

This dataset currently covers a random sample of domains from the CISA .gov registry (cisagov/dotgov-data). Coverage will expand to other public-interest domain lists over time.
